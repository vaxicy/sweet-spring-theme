# Sweet Spring Theme

A soft pastel color theme for Google Chrome. Sweet pink frames, a fresh light-green toolbar, and calming blue accents bring a gentle spring feel to the browser.

## Colors

| Element | Color |
| --- | --- |
| Frame | Soft pink `#F9B2D7` |
| Toolbar | Light spring green `#F6FFDC` |
| Background tab | Calm blue `#CFECF3` |
| Button background | Mint `#DAF9DE` |
| New tab background | White pink `#FFFAFC` |
| NTP link | Rose `#A13F72` |

The Google logo and shortcut icons on the new tab page are tinted automatically from the new tab background, so they blend with the white-pink palette.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions`.
3. Enable **Developer mode** (top right).
4. Click **Load unpacked** and select the project folder, or drag the packed `.zip` / `.crx` onto the page.

## Files

- `manifest.json` — theme definition (colors, tints, properties)
